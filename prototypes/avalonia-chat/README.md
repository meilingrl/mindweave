# Mindweave · 纯 Avalonia 交互原型

**状态：使用中、可丢弃的技术验证资产。** 用固定中文示例体验「阅读 → 选中文字 → 分支追问 → 返回来源」，不代表正式产品、完整 Markdown 能力或课程验收。

后续独立验证见 [LiveMarkdown 组件小样](../livemarkdown-chat/README.md)：使用 Avalonia 12 检查跨段选区与来源锚点；本原型的代码、应用包及已有数据保持独立。

## 启动

在本目录执行（SDK 固定为本机已有的 .NET 8.0.424）：

```sh
dotnet run --project src/Mindweave.Desktop/Mindweave.Desktop.csproj
```

macOS Apple Silicon 的自包含应用包位于 `artifacts/Mindweave Prototype.app`，可以直接打开，无需另外安装运行时。重新生成：

```sh
bash scripts/package-macos.sh
open 'artifacts/Mindweave Prototype.app'
```

Bundle ID 为 `local.mindweave.prototype`，使用本机临时签名，未做 Apple 公证。打包脚本仅生成此原型自己的产物。更新运行中的包前先正常关闭旧窗口，让退出流程完成保存。

## 体验路径

1. 打开「火车如何改变世界」，在回答中拖选 **蒸汽机**或同一段内的一句话。
2. 点击浮出的「继续追问」。新会话会带上选中文字与父会话入口；输入问题并发送，以约 16 秒分块显示固定示例回答。
3. 在新回答里继续选中文字，可以创建下一层分支。
4. 点击右上角「返回来源」，回到直接父会话，将选中文字所在行滚入视口并高亮。它与普通切换使用不同的导航语义。
5. 从侧栏或原文下方的已有分支入口切换，会恢复目标会话最近的阅读位置与未发送草稿，不新增分支。

附带了蒸汽机、内燃机两层已有分支，以及一个独立的天空主题。正文链接通过右键菜单打开；选中文字的右键菜单也提供追问与复制。输入区支持 Enter 发送、Shift Enter 换行。侧栏可收起和展开。

输出中可切换到其他会话继续阅读；原会话会持续生成，侧栏以小点提示。同一会话最多有一个输出任务，不同会话可各自生成。输入区按钮在生成时变为停止按钮；停止后保留已收到内容和状态。正在生成的回答完成或停止后才可创建分支，以免尚未闭合的 Markdown 改变选区含义；旧回答仍可选中和分支。

## 本地保存与重启

macOS 默认保存到：

```text
~/Library/Application Support/MindweavePrototype/state.json
```

这是原型自己的数据目录。界面变化约每 750ms 自动保存，正常退出前再保存一次。保存包含消息 ID 与正文、分支来源、当前会话、未发送草稿，以及消息块／字符阅读锚点。使用同目录临时文件写入后替换；不把同机状态文件称为备份，也未做多实例写入协调。

退出时若有生成任务，会提示继续探索或停止输出并退出。确认后暂时锁定工作区、停止任务并保存部分文字；保存失败时恢复窗口并在底栏报错，不关闭丢失内容。修复保存位置／权限后可再次关闭重试。

重启时，上次仍标记为生成中的回答改为「中断」，保留文字且不自动重跑。强制终止／机器异常时，最近一次自动保存之后的改动可能丢失；这不是生产级崩溃恢复保证。文件无法解析或来源不一致时，原文件保持原样，应用以临时状态打开并明确报错，不用示例数据覆盖它。

独立验证可指定另一个状态文件，先关闭已有实例再启动：

```sh
open 'artifacts/Mindweave Prototype.app' --args --data-file "$PWD/artifacts/manual-state.json"
# dotnet 启动也可通过 MINDWEAVE_PROTOTYPE_DATA_FILE 指定绝对文件路径。
```

需要重置示例时，先退出应用，手动把所用的 `state.json` 改名保留，再重新打开；文件不存在时才初始化内置样例。原型不会自动删除原记录。帮助窗口和底栏提示可查看实际保存位置。Windows 默认使用本用户 LocalApplicationData 下的 `MindweavePrototype/state.json`，尚未在 Windows 实机验证。

## 实现范围与限制

- **纯原生界面：** Avalonia 11.3.21 的 `SelectableTextBlock`、`Run`、原生滚动与弹出控件，没有 WebView、HTML 或浏览器渲染层。界面采用安静侧栏、窄正文和底部输入框；视觉方向参考 Codex 与 shad-ui，但未接入 shad-ui 依赖，也不声称复制其具体实现。
- **有意受限的 Markdown 子集：** 自写排版适配支持 1–3 级标题、单层有序／无序列表、段落、引用、粗体、行内代码、HTTP(S) 链接和围栏代码块。每个非空普通源行是一个独立块。它不是 CommonMark 引擎；未支持表格、图片、嵌套列表、嵌套格式、跨块统一选区等完整 Markdown 行为。链接以文字样式呈现，通过右键菜单打开。
- **单块选区：** 同一块内可以跨粗体、普通文字、行内代码或链接标签选择；保存显示选区及其在 Markdown 源文中的范围。不能从一个段落拖选到另一个独立控件，也没有复杂 Unicode／双向文字覆盖验证。
- **来源与阅读分开：** 来源包含父会话、消息、块、显示选区和源文范围；阅读位置保存消息块、可见行的字符索引与行内像素偏移。返回来源、普通切换、调整窗口宽度和重启恢复时，按当前排版重新测量对应文字。没有正文编辑功能；未验证复杂 Unicode、字体替换或任意文档改写后的引用稳定性。
- **增量排版：** 流式追加只更新发生变化的尾块，旧消息和已稳定段落的控件不重建；阅读旧内容时保持位置，在底部跟读时才跟随追加。仍在增长的尾块会随格式标记闭合而重排，尾块当前选区可能刷新；这不等于完整 Markdown 流式编辑器。
- **有限本地原型：** 已有 JSON 保存和固定内容的模拟流式任务；没有真实 AI、数据库、总结网络、完整 Markdown 引擎、生产级并发控制、跨设备同步或课程要求的完整导航架构。
- **示例内容：** 所有回复均为预先编写的演示文字；模拟发送不进行真实推理或事实校验。不要把这些文字作为历史／科学研究的已核实资料。
- **平台边界：** 已在当前 macOS arm64 环境构建与启动。Windows、Intel Mac、输入法、系统辅助功能及多种缩放比例尚未完成实际验证。

## 验证

```sh
dotnet test tests/Mindweave.Core.Tests/Mindweave.Core.Tests.csproj
dotnet build src/Mindweave.Desktop/Mindweave.Desktop.csproj -c Release
```

2026-10-23：31/31 测试通过，构建 0 警告、0 错误。包括：

- 格式标记隐藏后的原文范围映射、链接标签映射及无效选区拒绝。
- 分支来源、两层直接父级返回、普通切换恢复位置、草稿保留与不重复建分支。
- 根会话的固定回复不提示不存在的来源操作。
- 实际原生控件树可渲染列表／代码，避免文字被挂载到两个容器。
- Headless + Skia 的真实文字命中：鼠标按下／拖动／抬起选中粗体「蒸汽机」，再以鼠标点击浮层按钮，产生正确来源的新分支。
- 长段落末尾的选区返回后位于视口内，而非只滚动到段落开头。
- 模拟流在切换后继续、单会话拒绝重复生成、取消保留部分状态，粗体／链接／代码标记被拆到不同块时最终正文不丢字。
- 原生视图流式追加保留旧选区、视口和已完成段落控件；长段落在 1240→1000→1440 宽度变化后实际变窄／增高、右缘不越界，并恢复同一可见字符；列表、引用、代码的窄窗边界和窄／宽返回来源也有回归。
- 真实文件保存与损坏文件保护；两个不同 PID 的 writer／reader 子进程分别写入和读取，恢复来源、当前会话、草稿、字符位置，并把未完成任务标成中断。
- 退出确认可选择继续，确认后保存部分输出；保存期间禁止新编辑，保存失败保留可操作窗口与未保存草稿。

Headless 测试验证控件交互与几何行为，不能替代 macOS 的真实手势、输入法或 Windows 验收。桌面可见效果应以实际运行窗口为准。

首轮 macOS 应用包已通过桌面 UI 检查；其后用户亲自手动确认拖选、创建分支与返回来源都正常工作。这是当前 macOS 环境的基础交互证据，不外推到 Windows 或所有文本排版。

本轮真实桌面验证已完成：根会话模拟输出时切换到蒸汽机会话，输入未发送草稿；确认「停止输出并退出」后，应用进程确实结束。重新启动应用，恢复了当前蒸汽机会话和该草稿；根会话已收到的部分回答保留为 `Cancelled`，没有自动续写。这一项通过实际应用退出与新进程启动验证，区别于保存服务的独立 writer／reader 测试。

最终包 **v0.2.1** 已在真实 macOS 窗口复测：从 1240 拖窄到约 1007 再拖回 1240，正文换行确实随宽度变化，右侧没有裁切；窄窗进入蒸汽机子会话再返回来源，选中文字高亮位于可见区域，放大后仍可见。启动最终包后，先前保存的会话、停止回答和子会话草稿仍在。应用与这份原型数据保留供继续试用；这些结果只覆盖本次 macOS 场景，Windows 和完整产品验收仍未完成。
