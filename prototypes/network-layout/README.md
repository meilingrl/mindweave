# Mindweave 网络交互样例

状态：使用中的独立、可丢弃原生 Avalonia 样例，用户授权提前观察布局与交互。不是正式产品，不接 AI、数据库或原型存档；关闭不保存状态。

## 运行

```sh
cd prototypes/network-layout
dotnet run -c Release
```

本机也可打开 `artifacts/Mindweave Network.app`。该包依赖本机 .NET 10 运行时，只用于当前 Mac 试用，不是自包含发布物。使用 Avalonia 12.1.4，SDK 10.0.402。

## 体验

- 两组固定探索：火车历史与摄影入门，节点为圆点＋短标题。
- 单击查看元信息，不记已读；双击或“打开总结”进入固定演示正文，返回保留画布视口与选择。
- 默认双指滚动（横向／纵向）或空白拖动平移；⌘ / Ctrl + 滚动围绕指针缩放，侧栏 ＋ / − 围绕画布中心缩放；鼠标用户可勾选“鼠标滚轮直接缩放”；显示全部找回视口；标题搜索高亮，回车聚焦首个匹配。
- “新增关联节点”在所选节点附近寻找空位，旧坐标保持不变；未选择时从蒸汽机节点新增。
- 悬停节点扩大圆点、提亮标题与相邻连线；选中高亮沿父节点回溯到根的来源路径。悬停高亮为即时切换，另有平滑的轻微吸引；拖动有可调局部弹簧反馈。
- 虚线演示经过一个未总结会话；它不是 AI 推断的知识关系。
- 重置样例恢复初始节点；固定新增标题仅为布局素材，不保证新增内容和任意所选父节点语义相符。

## 验证与局限 · 2026-10-23

Release 构建通过，0 警告／0 错误。macOS 实机通过工具操作观察到单击未读、打开正文、返回后已读、新增节点且旧位置不变、平移缩放、显示全部、搜索聚焦。该轮未做自动回归、性能基准或 Windows 验证；用户随后确认基础交互可行，效果细节可后续微调。

算法是围绕父节点按角度放置，再按粗略标题包围盒寻找空位的早期径向原型。没有全图连续力模拟。尚不是按子树分配扇区的成熟布局，连线交叉、边与文字避让、群组留白、不同缩放下精确文字碰撞仍待改善。缩放围绕指针，放大空白可能让节点离开视口，可点显示全部。返回视口通过保留内存中的图视图实现，不证明持久化恢复。

图目前自绘，节点未建立正式键盘／辅助功能语义；架构并非正式四工程 MVVM 实现。已支持本次样例中的手动拖节点；未实现磁盘坐标存档、真实总结／来源跳转、自动二次命名、未总结根群组、布局重排与大规模优化。不把截图观感当成产品回顾价值证据。

`Program.cs` 为试验窗口和图；`artifacts/` 为可重新生成本机运行产物，只列入口不展开。

### 保守物理反馈样例 · 2026-10-23

状态：用户已确认本轮交互效果可行，验证结束；不据此扩大正式版范围。

- 侧栏“交互强度”0–100%，默认30%。0关闭运动，仍可拖动节点；后续已增加独立悬停吸引开关（见下）。
- 拖动节点保留其新位置，只对直接相连节点施加有阻尼的弹簧位移；邻居松手回原位置。位移最多48个画布世界单位，不传播到整个网络。不是全图力导向布局，也未实现碰撞排斥、新增局部让位或标题避让。
- 停稳后计时器停止，关闭/移除视图也停止。拖动位置和强度仅保留在本次运行内；重置恢复布局，保留强度设置。
- `LocalMotion.cs` 包含独立数值模型和无窗口检查入口：`dotnet run -c Release -- --check-motion`。检查零强度、非零响应、位移上限、回稳休眠、中途关闭与强度排序，通过。Release 构建0警告／0错误。
- macOS 工具操作确认根节点拖动后留在新位置，其他节点回原位，侧栏显示所选节点；滑动条0和100可更新。连续拖动时的运动观感仍以用户实测为准，未做大规模性能或Windows验证。

### 悬停吸引升级 · 2026-10-23

- “悬停轻微吸引”默认开启，可单独关闭；共用交互强度，默认30%。指针距圆点90个界面逻辑像素以内时轻微朝指针偏移，100%时最大5个逻辑像素，30%时最大1.5个。缩放不放大该装饰位移；离开范围/画布后平滑回位，停稳后停止刷新。
- 悬停位移只用于绘制，不改变布局坐标。命中兼顾原位置与当前显示位置；按下时停止悬停运动，交给已有拖动逻辑。平移、缩放、适配视图时清除旧悬停目标，等待下一次鼠标移动。
- 数值回归补充吸引方向、最大位移、作用范围、离开回位停稳与零强度检查，连同原有拖动检查通过；Release构建0警告／0错误。实机确认新开关正常切换、节点仍可点击选择，应用包已更新打开。工具没有独立悬停移动接口，连续悬停的实际观感待用户试用，不以数值检查代替体验验收。
