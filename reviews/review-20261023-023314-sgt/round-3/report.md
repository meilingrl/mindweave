# 第三轮汇总与裁决：v3 → v4

[产品流程推演](product.md) · [架构时序推演](architecture.md) · [验证/课程流程推演](verification.md)

三份独立报告覆盖两层分支与返回/重启、V1/C1/手改采用、两个未总结根的回顾、并发排队/改配置/迟到块、退出保存失败返回、祖先冻结、标题竞争、Markdown降级及课程演示/交付。主 Agent 已逐份核对。所有“预期/唯一结果”是静态流程判定，**不是实机、数据库或产品价值验证**。

## 裁决

- MW-02 编辑边界、MW-04/06 退出失败回到工作区、MW-12 标题保护，在 v3 推荐规则下能解释指定反例。产品/验证审查者没有发现新增高价值问题。
- 架构审查发现一个新高价值 MW-06 子例：退出保存失败后，内存源正文已终态；只保存分支＋来源而未保存引用依据，再强制终止会留下无法在已保存源文中成立的引用。主 Agent 采纳。
- v4 只补一条通用不变量：持久来源依赖的正文/终态/冻结边界先提交或与引用同事务提交；失败不留下声称已保存的来源。适用于分支和总结，不复制全部祖先、不要求逐 token 落盘。

## 保留与未决

未改用户已确认结论的历史身份，不重新选择技术路线，不新增产品模块。D1–D8 类型的体验选择、课程口径和运行验证仍未完成。其余问题沿原 MW 编号保留状态，不反复制造重复缺陷。

[v4 需求](../v4/initial-requirements.md)与[v4 架构](../v4/architecture-discussion.md)已形成并冻结。因为本轮出现新的高价值子例，本轮不计为无新问题收敛轮；继续做范围受限的第四轮复查，最多不超过第五轮。
