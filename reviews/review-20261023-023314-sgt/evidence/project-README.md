# Mindweave

面向个人日常好奇与非专业专题学习的 AI 对话探索工具。本轮 macOS 核心交互原型验证已获用户确认，当前继续讨论正式版架构，尚未建立正式产品实现。

| 入口 | 用途与范围 |
| --- | --- |
| [初始产品需求](initial-requirements.md) | 产品定位、核心流程、第一版范围和价值验证 |
| [架构与技术讨论](architecture-discussion.md) | 正式版已确认决策（第 10–17 节）、待确认的状态恢复与下次讨论起点（第 18 节），以及课程约束和验证记录 |
| [Avalonia 聊天原型](prototypes/avalonia-chat/) | 只列入口，不展开：独立的视觉与分支交互验证资产；运行方法和限制以其中 README 为准 |
| [LiveMarkdown 组件小样](prototypes/livemarkdown-chat/) | 只列入口，不展开：独立 Avalonia 12 组件验证，检查跨段选区、来源锚点、重排与追加；不替换已验收聊天原型 |

原型不等于正式产品，也不代表整条技术路线或课程要求已经验收通过。
