# Ideas

First drafts of possible directions for the phase after current development. Started 2026-11-22.

**Standing.** Nothing here is agreed. These files are not requirements, not architecture and not design. They record thinking so it is not lost, and they are refined one by one in discussion with the owner. When a draft conflicts with [requirements](../requirements.md) or [architecture](../architecture.md), those win.

**What happens to a draft.**

- **Adopted:** the owner decides. The direction gets an entry in [evolution.md](../evolution.md), then a design note when work is about to start. The draft is removed, because its content has moved.
- **Dropped:** the file is removed. One line with the reason stays in the table below.
- **Still open:** it stays here and keeps changing.

Each file starts with its status and the date of its last discussion.

## Where these came from

The owner named three directions on 2026-11-22: free credits for new users, more platforms, and polishing the product's inner quality. The owner's aim, in their words: let Mindweave flow through daily life, with no fretting over summarizing and managing, and no being constrained by form and tools. The project is open source and not for profit. A direction is judged by whether it makes the software better and whether it leaves technical ideas others can use.
