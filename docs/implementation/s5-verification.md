## 实施判断与判断错误的代价

以下按账本顺序公开本阶段截至当前的全部九项Ruling；均为既有设计范围内的实施判断，未改变共享需求或费用授权。

| 判断 | 理由及可见效果 | 判断错的代价 |
| --- | --- | --- |
| S5-R1 自动放置参照已保存坐标 | 不间接固化尚未保存的整理；之后不保存时，新节点保留自己的已提交位置 | dirty图可能暂时重叠，需要整理或调整算法 |
| S5-R2 集中可调数值参数 | 默认extent200×112，径向200、组间320、碰撞24／最多24轮；坐标界1e9，缩放0.15–2.5、padding48、倍率1.15 | 需按实测调整密度和边界，不把单例测量当规模保证 |
| S5-R3 两阶段离开许可 | 以工作区／修订约束延期Discard，取消后布局与任务都保留 | 生命周期集成复杂度增加，需要严格排空和重验 |
| S5-R4 保留无INetworkStore替身的旧列表 | 正式SQLite走网络；已有S0／受控替身继续列表 | 暂有两种元信息呈现需要维护，避免无关测试替身迁移 |
