### Minor (Nice to Have)

**S2-M1 / inherited Task1-M1 — Compute shared viewport ownership once per scroll event.**

- **Location:** `src/Mindweave.Desktop/Markdown/MarkdownMessageView.cs:50`, `:59`, `:115-120`; additional per-scroll read capture at `src/Mindweave.Desktop/Views/ChatView.axaml.cs:43-48`.
- **Issue:** Every attached message subscribes to the shared ScrollChanged event. Each message then enumerates the same shared visual subtree and all Markdown text blocks to find the first visible block, although only one message can own that block. With M messages and B total blocks, traversal work is roughly O(M × B) per event before other layout work.
- **Impact:** This is a concrete scaling cost for long conversations and frequent scroll/layout events. The reviewed evidence does not establish a user-visible native latency threshold or show an ordinary S2 workflow failing, so it remains P3/Minor and does not block this code gate.
- **Recommended follow-up:** Compute/cache the owner once at the shared viewport level, invalidating when geometry changes, and distribute the resulting pin to the owning message. Preserve signed viewport Y, single ownership and the newer-scroll-wins checks; retain the three existing multi-message regression tests. Use a representative long conversation to measure the improvement before making performance claims.
