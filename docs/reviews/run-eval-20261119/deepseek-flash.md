- ✓ 回答完成：Complete
- ✓ 包含 100
- ✓ 不调用工具：没有调用工具

回答：

> 在标准大气压（1 atm，即 101.325 kPa）下，水的沸点是 **100 摄氏度**。
> 
> 几点补充：
> - 这里的“沸点”指液态水的饱和蒸气压等于外界气压时的温度；气压降低，沸点下降（如高原上不到 100 ℃）；气压升高，沸点升高（如高压锅）。
> - 严格说，这个 100 ℃ 正是摄氏温标历史上的两个定义点之一（另一是 0 ℃ 冰点），现行温标下约为 99.97 ℃，日常使用取 100 ℃。
