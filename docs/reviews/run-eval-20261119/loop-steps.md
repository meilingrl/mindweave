# 运行循环改进 L1–L11：每一步的评测（2026-11-19）

改进按 [agent-loop.md](../../design/agent-loop.md) §5 的顺序分四步实施，每一步之后对 deepseek-flash（配置 `default`，与[基线](README.md)相同）跑一次真实评测（用户 2026-11-19 给的额度：共 4 次）。评测的网络是假的，不花搜索额度。同一模型两次运行之间本有波动（基线 README），单次一两项的差别不说明问题。

“请求”与“工具调用”是被测回答的模型请求与工具调用；token 是服务报告的被测回答的输入与输出。
