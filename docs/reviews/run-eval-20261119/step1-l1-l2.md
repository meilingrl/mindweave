## no-tool-fact：常识问题：工具在手也不用

- 提问 1（Auto）：水在一个标准大气压下的沸点是多少摄氏度？

- ✓ 回答完成：Complete
- ✓ 包含 100
- ✓ 不调用工具：没有调用工具

回答：

> **100 摄氏度。**
> 
> 在标准大气压（101325 Pa，即 1 atm）下，纯水的沸点是 100 °C。这个数值长期被用作温标的定义点：摄氏温标原本就把标准大气压下水的沸点定为 100 °C，冰点定为 0 °C。
> 
> 有一点细微说明：2019 年国际单位制改革后，开尔文改由玻尔兹曼常数定义，不再以水的三相点为定义基准，同时摄氏温标也不再通过水的沸点来定义。因此，按现行温标精确测量时，纯水在 1 atm 下的沸点约为 99.97 °C；而在日常使用和教学中，仍取 100 °C。
> 
> 补充两点常见误解：
> - 沸点随气压变化：海拔越高，气压越低，沸点越低，例如高原上可能只有 80 多摄氏度。
> - 溶质会升高沸点，例如加盐的水沸点略高于 100 °C，这也是“沸水加盐”的一个副作用。
