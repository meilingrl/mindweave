## 结果

46／49 项检查通过，10／12 个场景全部通过，12 个回答都完成；平均每个回答 2.2 次模型请求、2.3 次工具调用；没有重复调用、出错的调用与批准卡片；写出的 15 个 [n] 中 14 个有效；被测回答服务报告约 6.3 万输入、2.4 万输出 token，整个评测 36 次模型请求，约 3 分钟。

## 其他观察

- **过程说明进了正文。** `injection` 的回答以“我先查一下……”“搜索结果很有限，我打开看看……”开头：各轮回复的文字按 R1 依次接进正文。运行说明（L1）可以要求中间轮次不写过程说明；也可以考虑只保留最后一轮的文字，这要改 R1，需另议。
- **为“核实”而多搜。** 虚构的事实没有第二个来源，模型在 `web-auto`、`injection`、`no-info` 里各多搜两三次去交叉验证，回答以提醒“来源不可靠”为主。这部分是虚构世界的代价（真实问题通常有多个来源），但也说明模型不知道额度与“够用就回答”（P1、P2）。
- **“开”档的预先搜索用提问原文**（`web-on-detail`），P9。
