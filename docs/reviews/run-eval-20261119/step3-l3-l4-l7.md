## no-tool-fact：常识问题：工具在手也不用

- 提问 1（Auto）：水在一个标准大气压下的沸点是多少摄氏度？

- ✓ 回答完成：Complete
- ✓ 包含 100
- ✓ 不调用工具：没有调用工具

回答：

> 在一个标准大气压（101.325 kPa）下，纯水的沸点是 **100 摄氏度**。
> 
> 补充几点说明：
> 
> - 摄氏温标最初就是按照水的冰点（0 °C）和沸点（100 °C）定义的，因此在很长一段时期里，水的沸点按定义就是 100 °C。
> - 按现代温标的严格测量，在 101.325 kPa 下，纯水的沸点约为 99.97 °C；它和 100 °C 的差别非常小，在中学和日常使用中完全可以直接取 100 °C。
> - 沸点随气压变化：气压降低，沸点就会下降。比如海拔较高处，水不到 100 °C 就沸腾了；用高压锅时气压升高，沸点则会超过 100 °C。
> - 这里说的是纯水；如果水中溶有盐等溶质，沸点会略微升高。
