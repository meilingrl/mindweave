# S5 总结网络

验收依据：交接 §2.7、§5 S5（“需求 §11 布局两行；保存故障注入”）；需求 §7.2（网络短标题）、§7.3、§7.4、§11；架构 §11、§11.1–11.4；U3（新生成总结的位置直接保存）；MW-C12；网络样例 README。拖动（D8）、装饰动效与 3D 不在本阶段。

## 节点短名（S4 试用意见）

总结名称（显示名、版本标题）保持 S4 的机制，允许较长。网络节点另用**短名**：

- 每个版本存一个短名（迁移 v7：`summary_version.short_title`）。总结请求的输出在标题行后加一行“短名：…”（2–8 个字，表达知识点）。解析不到时用标题前 8 个字。
- 节点短名取**当前版本**的短名，所以采用候选、设为当前后自动跟着变，不改节点身份、不增版本。手改保存的版本沿用基线的短名。
- 短名可以重复；选中节点后的详情显示完整显示名、来源会话与时间。短名不参与同名二次命名（那是显示名的事）。
- 迁移前已有的版本没有短名，用标题前 8 个字。

## 投影（Application）

`NetworkService.ProjectAsync(工作区)` 只读一次，不读正文：

- **节点**：本工作区每个总结节点：ID、短名、显示名、标记、来源会话与其标题、创建时间、所属根探索（来源会话的根会话）。
- **边**：对每个节点，沿来源会话的祖先链（`branch_context_range`，按深度）向上找最近的、有总结的祖先会话；有则连一条边。中间跳过的会话数记在边上（0＝直接父子，实线；≥1＝虚线，并标“经 N 个未总结会话”，详情列出完整路径的会话标题）。边只表示真实探索来源。
- **群组**：按根会话分组；根会话没有总结也照样作为群组依据，不制造节点。

## 布局（Desktop，纯计算模块）

`NetworkLayout` 输入节点（含父节点、群组、创建顺序、标签宽度）与已有坐标，输出坐标；不依赖控件，单元测试覆盖确定性。

- **整体布局**（首次或“整理布局”）：群组按根会话创建时间从左到右排列，彼此留白；群组内以径向树展开——根在中心，每层一圈，扇区按子树叶子数分配；之后做有限次数的标签包围盒碰撞修正。
- **放置新节点**：已有坐标全部保留。新节点放在父节点附近：在父节点外圈按固定角度序列找第一个不与已有节点（含标签）重叠的位置；没有父节点但群组已有节点时放在群组外缘；新群组放在全图右侧。
- **确定性**：输入按创建时间与 ID 排序，同样的输入总得到同样的坐标（MW-C12：直接保存失败时下次重算结果一致）。

## 坐标与保存

- 迁移 v7：`node_layout`（工作区＋节点唯一，X、Y 为节点中心的画布坐标，更新时间），随节点删除（CASCADE）。不建视口表。
- **网络会话**：每个工作区在内存里有一份网络状态（坐标、布局修订号、已保存修订号、视口、选中），由工作区运行时持有，所以离开网络去读总结再回来，视口与选中都还在；切换工作区或重启后丢弃（视口不持久化）。
- **新节点直接保存**（U3）：加载网络时，没有坐标的节点按放置规则计算后**逐行**写入该节点自己的位置，不产生待保存状态，也不提交其他待保存改动。参照的是**当前内存布局**（网络已打开时就是你眼前的图），这样新节点出现在你看到的来源节点旁边；代价是：若你随后对一次“整理布局”选择不保存，新节点保存的位置挨着整理后的父节点位置，下次进入时会离父节点稍远——位置仍有效，可以再整理。直接保存失败不提示、不阻止离开，下次进入按同样输入重算。
- **整理布局**产生待保存状态（软盘按钮启用并带圆点）。**保存**（按钮或 ⌘S／Ctrl+S）捕获当前修订号的全部坐标快照，一个事务写入；只写仍存在的节点（已删除的节点不会被写回）。保存期间可继续操作；保存成功只把“已保存修订号”推进到快照的修订号——期间又整理过，按钮仍保持待保存。失败保留内存坐标和待保存状态，提示“布局保存失败，改动仍保留在当前窗口”，可重试。
- **离开提示**：有未保存布局时，切换工作区或退出应用先问“保存并继续／不保存／取消”；选“保存并继续”而保存失败则不离开。打开总结再返回不提示。

## 视口

- 首次进入网络、切换工作区回来、重启后：适配全部（依据节点与标签边界、可用区域与边距，缩放限制在 0.25–2.5）。
- 从总结页返回：保留中心、缩放与选中。窗口大小改变：保留中心与缩放。
- 新节点不强行移动视口；整理后适配新布局；“显示全部”只改视口不动节点；标题查找把匹配的第一个节点移到中心并选中。

## 交互与界面

- 画布自绘：连线（实线／虚线）、节点圆点、短名、选中描边、未读点。状态不只靠颜色：未读节点圆点旁有“•未读”文字之外的形状标记（实心小点），候选更新用“↻”，详情里写全文字。节点大小一致，不表示掌握程度。
- 单击选中并在侧栏显示详情（显示名、短名、标记文字、来源会话、生成时间、经过的未总结会话），不计已读；双击或“打开总结”进入总结页；“回到来源会话”进入会话。
- 平移：拖动空白、触控板滚动；缩放：⌘／Ctrl＋滚动围绕指针、＋／－按钮围绕中心；可选“鼠标滚轮直接缩放”。
- 键盘与辅助功能：画布节点自绘，没有逐个控件的辅助功能语义；因此保留 S4 的**列表视图**（可切换），列表里的每个总结都是普通按钮，可键盘操作与朗读。这是相对架构“节点用轻量普通控件”的偏离，记为 D-018。
