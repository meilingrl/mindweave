# Windows 实机验收清单（S6）

需求 §11 的每个场景一行，在笔记本的**桌面会话**里用发布的程序逐项走（不能经 SSH：凭据管理器、输入法、文件对话框、窗口激活只有桌面会话可用）。自动测试已覆盖行为本身（见“自动覆盖”列，Windows 实机与 CI 都跑）；这里验证的是真实系统上的手感与集成。

准备：运行 `E:\mindweave-claude-auto\app-s6\Mindweave.exe`（发布后的路径以阶段报告为准）。想不碰日常数据时，先在 PowerShell 里 `$env:MINDWEAVE_DATA_DIR='E:\mw-try'` 再从同一窗口启动。在“设置”里填服务与密钥。

结果栏填 通过／不通过／跳过，不通过时写一句看到了什么。
