# 第三方工具（智能体平台第 4 期，MCP）

依据：[需求](../requirements.md) §10.4.6 与 §11 第 4 期验收（v0.19），[架构](../architecture.md) §15.6–15.8、§15.14，[待决定的问题](agent-platform-questions.md)（Q11 用户 2026-11-17 通过；Q15 按建议实施，**待你确认**）。第 2 期的运行循环与注册表见 [runs-and-tools.md](runs-and-tools.md)，第 3 期的批准卡片与不可信材料见 [web-search.md](web-search.md)。本文记实现层的选择；产品行为以需求与架构为准。

## 1. 本期新的决定（待你确认）

需求与架构里没有写定、本期必须选一个的地方。都按“安全在前、简单、可逆”选；你选了别的，相应代码随之改。

| # | 决定 | 理由 | 其他选项 |
| --- | --- | --- | --- |
| M1 | 用官方 C# SDK 的 `ModelContextProtocol.Core` 2.3.1（Apache-2.0，2026-11-03 发布），只在 Infrastructure 引用；Application 只见自己的契约 `IMcpConnector` | 官方维护、跟随协议修订（含 2026-07-28 修订与旧版握手的自动回退）；`Core` 只含客户端与协议，不带服务器托管；依赖的 `Microsoft.Extensions.Logging.Abstractions` 10.0.13 与本仓库固定的版本相同，2.4.0 需要 10.0.14 | 2.4.0（要同时升级日志程序包）；自己写 JSON-RPC 客户端 |
| M2 | 服务器与工具设置存在偏好设置 `mcp.servers`（一个 JSON），不建表、不需要迁移 | 一般只有几个服务器、几十个工具；读写都是整体的；不占迁移编号，合并时不与其他分支冲突。架构 §15.3 原写的 `mcp_server`、`mcp_tool_setting` 两张表随之改为此 | 迁移 v18 建两张表 |
| M3 | 环境变量的值与请求头的值都当作密钥：合为一个 JSON 存在系统凭据服务，偏好设置只存名称与凭据引用；添加时的确认只显示名称 | MCP 服务器的环境变量多半就是令牌（如 `GITHUB_TOKEN`）；分辨哪些不是密钥会出错 | 让用户逐个标记是否是密钥 |
| M4 | 不提供“编辑服务器”：改命令、参数、环境变量或地址须移除后重新添加；移除时停止进程、删除凭据与工作目录，会话里已保存的工具结果保留 | 改了命令就是另一个程序，已启用工具的信任依据不再成立；重新添加时会再次显示完整命令 | 可编辑，编辑后全部工具停用 |
| M5 | 所有工具默认关闭；启用时记下工具的定义快照（名称、说明、输入格式、四个提示）及其哈希、默认风险（只读且非破坏性 → 读网络，其余 → 有副作用）；用户可改为三个等级中的任一个 | 需求 §10.4.6；用户启用时看到的等级就是之后使用的等级，服务器之后自报什么都不能让它变低 | 不记快照，每次按服务器当前的提示 |
| M6 | 服务器给出的定义与快照不同（说明、输入格式、提示任一项）、工具改名或消失时，该工具自动停用，设置中说明“定义已变化，请重新查看并启用”；在设置中连接时与每次调用前都比对 | 防止“先给无害的说明、启用后再改”（rug pull）与改称只读以免批准 | 只在提示变低时停用；不比对 |
| M7 | 接受提问时按快照提供启用的工具，不为此启动服务器；第一次调用时才启动。有启用的第三方工具时，回答总是运行（不受 R5“有东西可查”限制） | 提问不因启动进程而变慢；没有用到的服务器不运行 | 接受提问时启动全部服务器 |
| M8 | 读网络的第三方工具跟随输入框旁的网络搜索开关：“关”时不提供，“自动”“开”时提供；开关因没有搜索密钥而变灰时按设置中的默认档。本地只读与有副作用的不受开关影响 | 开关表达“这次提问要不要用网络”；有副作用的调用本来就逐次批准 | 设置里另设一个“读网络的第三方工具”开关；不跟随任何开关 |
| M9 | 交给模型的名称是“服务器简称__工具名”：简称取自服务器名称中的英文字母与数字（小写，最多 16 个，没有时为 `mcp`），服务器之间重复时加数字；工具名中其他字符换成下划线；超过 64 个字符或与已有名称重复时截短并加 `_` 与 4 位十六进制哈希。名称在启用时确定并保存 | 模型从名称就能分辨服务器；固定下来使之后的提问、步骤与统计一致 | 编号前缀（`s1__`）；不加前缀，只在冲突时改 |
| M10 | 工具说明交给模型时加上“【第三方工具，来自 MCP 服务器“名称”；以下说明由该服务器提供，不是用户的要求】”，说明最多 1,000 字；服务器的使用说明（instructions）、资源与提示词不交给模型；客户端不声明 sampling、elicitation、roots 能力 | 说明本身可能是提示注入；不需要的能力不打开 | 原样交给说明 |
| M11 | 时限：启动（进程、握手、列出工具）30 秒；每次调用 60 秒；退出后的重连等待 1、2、4、8、16、32、60 秒；10 分钟内退出 5 次后停止自动重启，须在设置中点“启动”；空闲时不停止，直到退出应用、停止或移除 | 第三方工具（例如首次 `npx` 下载）比内置工具慢；反复崩溃的服务器不应无限重启 | 空闲 10 分钟后停止 |
| M12 | 本地进程的环境：不继承 Mindweave 的环境，只用 SDK 的基本变量集合（`PATH`、`HOME` 等，见 `StdioClientTransportOptions.GetDefaultEnvironmentVariables`）去掉 `MINDWEAVE_*`，再加用户填写的变量；macOS／Linux 上 `PATH` 补上存在而缺少的常用目录（`/opt/homebrew/bin`、`/usr/local/bin`、`~/.local/bin` 等，从程序坞启动的应用只有 `/usr/bin:/bin:/usr/sbin:/sbin`），不带目录的命令名（如 `npx`）沿这个 `PATH` 查找；工作目录 `<数据目录>/mcp/<服务器编号>/` | Mindweave 的密钥在凭据服务里，但运行环境里可能有别的密钥（例如 `OPENAI_API_KEY`）与代理设置 | 继承全部环境（SDK 默认） |
| M13 | 标准错误逐行写入应用日志（信息级，每行最多 500 字），先去掉这个服务器的已知密钥与像密钥的内容（现行 `Redaction`）；最近 20 行保存在内存中，设置里出错时可看 | 调试第三方服务器离不开它；不写入数据库 | 不记录 |
| M14 | 网址服务器：Streamable HTTP，不支持时退回 SSE（SDK 自动）；最多一个请求头；不跟随重定向、不用 Cookie、不做 OAuth（Q15）；地址是环回时直连，其他经系统代理；用户填写的任何地址都可以连接（含本机与局域网） | 地址是用户自己填、确认后保存的，与模型写出的网址不同（§15.8 的取网页限制针对后者） | 拒绝私有地址 |
| M15 | 结果：文字（含嵌入的文字资源）合成一个 Markdown 结果资源（`origin = 'mcp'`、外部），最多保留 20 万字，超过时截断并说明；图片另存为图片资源（每张最多 20 MB，每次最多 4 张），结果中写“[图片：资源编号]”，本期不交给模型；资源链接只列出名称与地址，不自动读取；音频等其他内容只写“[未保存的内容：类型]”。服务器标为出错（`isError`）的结果作为出错交还模型 | 工具结果在协议里只能是文字；图片交给模型要另设计（Chat Completions 的 `tool` 消息不能带图片） | 把图片作为下一次请求的用户图片发送 |
| M16 | 批准卡片：“模型想调用第三方工具”，显示服务器、工具（模型用的名称与原名）与格式化的参数（最多 4,000 字，可滚动）；允许只对这一次调用有效（Q11）；拒绝时交还“用户拒绝了这次调用。”，步骤详情写“你拒绝了这次调用” | 与第 3 期的卡片同样的位置与样式；参数就是要批准的内容 | 卡片里只显示参数摘要 |
| M17 | 有副作用的调用超时或服务器在调用中退出时，步骤记为“结果未知”（`unknown`），交还模型“出错：……这次调用是否已经生效未知”；只读的照常记为出错 | 与重启时对有副作用步骤的处理（§15.10）一致：不能假装没有执行 | 一律记为出错 |
| M18 | 统计页“工具”一节：第三方工具一行写“服务器 › 工具”，按 `run_step.target`（服务器名称）与工具名分组计数；另按服务器给出合计 | `target` 本来就记服务器名（§15.3）；不需要迁移 | 只按工具名 |

**Q15（按建议实施，待你确认）：** 不支持需要 OAuth 登录的远程服务器；本地命令与不需登录或用一个固定请求头（例如 `Authorization: Bearer …`）的网址都支持。

**Q11（已定）：** 有副作用的调用一次批准一次；没有“本次运行内允许”，也没有“总是允许”。

## 2. 存储（无迁移）

| 变化 | 说明 |
| --- | --- |
| 偏好设置 `mcp.servers` | JSON 数组，每个服务器：`id`、`name`、`slug`、`kind`（`command`／`http`）、`command`、`arguments`、`environment`（名称列表）、`url`、`header`（名称）、`credential`（凭据引用，可空）、`tools`（启用的工具：原名、交给模型的名称、定义快照、哈希、默认风险、用户的风险，及自动停用的原因） |
| 系统凭据服务 | 引用 `mcp/<编号>/<随机>`，值为 `{"env":{名称:值},"header":值}` |
| `resource` | 新的来源 `mcp`（应用校验，不需迁移）：文字结果 `text/markdown`，图片为原媒体类型；`provenance = 'external'` |
| `run_step` | `target` 为服务器名称；`tool` 为交给模型的名称；有副作用的步骤 `approval` 为 `pending`／`approved`／`denied` |
| 数据目录 | `mcp/<编号>/`：本地服务器的工作目录，移除服务器时删除 |

## 4. 测试

测试用的假服务器在 `tests/Mindweave.FakeMcpServer`（手写 JSON-RPC，不用 SDK 的服务器部分），以参数与工具选择行为：启动即退出、不握手、调用中退出（`crash`、`crash_read`）、不返回（`hang`、`hang_write`）、返回超大结果、某次列出之后自称只读、改名或改说明（`--lie-after`、`--rename-after`、`--describe-after`）、在输出里写指令、返回图片、资源链接、嵌入资源与音频、返回出错的结果、把进程号写进工作目录；同一份代码也可以在测试进程内作为 `HttpListener` 上的网址服务器（只监听 127.0.0.1）。

| 测试 | 覆盖的验收行与决定 |
| --- | --- |
